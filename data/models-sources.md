# /models sources — snapshot 2026-11-20

Provenance for `data/models.ts`. Plain list, one line per model.

- **AA**: every AA-measured value comes from one set of fetches on 2026-11-20 of the per-model records in Artificial Analysis's Next.js payload, still on **Intelligence Index v5.0.1** (no index change since 2026-11-12; changelog under "Version History" on https://artificialanalysis.ai/methodology/intelligence-benchmarking). Same method as 2026-11-16: AA's model pages embed only the page's own variants plus a comparison set (the full set ships as an encrypted `/data/<hash>.txt` file, not used here), so every row's own model page was fetched (`https://artificialanalysis.ai/models/<slug>` for all 218 AA slugs in the last snapshot plus every release slug on the leaderboard: 309 pages, all returned 200), and the plain `initialModels` records were read from each: 476 distinct variants, and every variant that appears on more than one page is identical on all of them. https://artificialanalysis.ai/leaderboards/models embeds AA's 287 current variants and was used to sweep for new releases. Field mapping unchanged (speed `headline.outputSpeed`, latency `headline.timeToFirstToken`). Prices are rounded to 3 decimals. A URL below may be a variant's own page (e.g. `grok-4-6-xhigh`) rather than the release slug; every one returned 200 and embeds the named variant.
- **llm-stats**: https://api.zeroeval.com/leaderboard/models/list (release sweep: since 2026-11-16 it adds Qwen4-Max, Hy4 flash, GPT-6.2 Astra, GPT-6.2 Sol, Gemini 4 Neon and Aion 1.0 Instruct) and `/leaderboard/models/<id>`; it has no entry for MAI Code 2, MAI Code 2 Flash, SenseNova-Loop-9B, Sage S2.1 Flash or JoyAI-VL-Preview.
- **Hugging Face**: `/api/models?author=…&search=…` and `/api/models/<repo>` (creation date, safetensors parameter total) plus each repo's `config.json` for context length.
- **Epoch ECI**: `eci` column of `epoch_capabilities_index/eci_scores.csv` in https://epoch.ai/data/benchmark_data.zip, fetched 2026-11-20. Epoch added GPT-6.2 Astra (2026-11-17, 174.17) and refit the index: 90 of the 95 existing ECI values moved, almost all by under 0.2 (the largest: Llama 3.1 8B 111.14 → 110.78, DeepSeek V4.1 Flash 156.7 → 157.0, Grok 4.7 156.18 → 156.43; GLM-5.3, Sonnet 4.6, o3, QwQ-32B and Qwen3.8 Max (0803) did not move).
