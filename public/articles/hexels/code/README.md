# Hexels toys

CPU-only experiments for the article `hexels`. Python 3.12, numpy and torch (CPU); images are synthetic and generated by `toy_images.py`.

- `tilings.py` writes `tilings.json`: equal-count square, hexagon and triangle lattices with constant or affine colour, axis-aligned and best-of-ten-rotations. No optimiser.
- `primitives.py` fits N optimised primitives (Gaussian, hexagon, round and square controls; constant or linear colour). `run_grid2.py` (and the earlier `run_controls.py`) append to `grid.jsonl`; rows for the linear kinds without `"ver": 2` came from a first, weaker ramp parameterisation and are ignored. `fit_strip.py` renders the figure strip.
- `prop_g3.py` checks Proposition G.3 of the paper numerically (`prop_g3.json`).

All run single-threaded; the scripts expect to be run from this directory.
