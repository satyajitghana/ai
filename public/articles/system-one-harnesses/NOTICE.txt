/articles/system-one-harnesses ("Five harnesses for a model that cannot write").

Each file below comes from the upstream repository named beside it. The
clips are transcodes of recordings published there: no frames were added,
removed or reordered; they were rescaled, re-encoded to VP9/H.264, and their
(silent) audio tracks dropped. Posters are single frames of the same
recordings. The still is a rasterised copy of a diagram committed upstream,
and its own entry records the one rendering change.

  The repository publishes this diagram as an SVG and serves it from the
  README. It is rasterised here to PNG at 1600 px wide on an opaque white
  background, with one change: the SVG asks for Inter, which is not
  installed on the rendering machine, so the font stack was set to Hanken
  Grotesk to keep the label metrics close to the upstream layout. No
  shape, colour, label or position was altered. The repository also ships
  architecture-dark.svg, the dark-mode twin of the same diagram; the light
  one is committed here because it reads in both of this site's themes.
