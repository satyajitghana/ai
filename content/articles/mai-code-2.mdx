On 17 November, at Ignite, [@msdev posted](https://x.com/msdev/status/2122760423699268086) a 53-second film and four lines: MAI Code 2 "brings frontier price-performance for everyday enterprise coding tasks", MAI Code 2 Flash "brings affordable and high-quality coding for routine work at scale", and both are in GitHub Copilot today. The replies asked the obvious things. "Where is the benchmark." "Why are these not on openrouter." "If they would be any good you would publish them to @ArtificialAnlys."

The benchmark is there, if you know where to look. [Microsoft AI's announcement](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/) gives only ratios: averaged over DeepSWE 1.1, Terminal-Bench 2.1, SWE Atlas and FrontierCode v1.1, MAI Code 2 delivers "98% of the performance of GPT-6.1 Sol at 40% of the cost, and 96% of Claude Opus 5.5's performance at just 5% of the cost". The [model page](https://microsoft.ai/models/mai-code-2/) draws those as two charts, and each chart is an embedded HTML document carrying its data as a JSON object: a pass rate and a cost per task for every model on every benchmark. That object is the most useful thing Microsoft published this week, and it is what the rest of this piece is built on. The [model card](https://microsoft.ai/pdf/MAI-Code-2-And-MAI-Code-2-Flash-Model-Card.pdf), two [data](https://microsoft.ai/pdf/MAI-Code-2-Data-Card.pdf) [cards](https://microsoft.ai/pdf/MAI-Code-2-Flash-Data-Card.pdf) and GitHub's [price table](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing) fill in the rest.

Nothing here was run: there are no weights. Every number is Microsoft's, GitHub's or a named third party's, or my arithmetic on them, and the sentence says which.

## Two models, one recipe, a 2.8T base

The model card describes a family. Both models are decoder-only transformers with sparse mixture-of-experts layers and an integrated vision encoder, "pre-trained and post-trained by Microsoft from scratch", sharing "the same lineage, architecture family, training recipe" and differing "mainly in size".

| | MAI Code 2 | MAI Code 2 Flash |
|---|---|---|
| Parameters (card, section 1) | 77B active, 3B embedding, about 2.8T total | 12B active, about 398B total |
| Pre-training | about 50T tokens, then about 150B for long context | about 25T tokens (22T text, 3T image), logit-distilled from a larger MAI teacher |
| Base (data card) | "MAI 80B Base Model (Internal)" | "MAI 12B Base Model (Internal)" |
| Post-training (data card) | 1.4 million task prompts, about 166B trained tokens, 16 task families | about 537,000 task prompts, 5.1 million completed rollouts, 12 task families |
| Context | 1,050,000 tokens: 922,000 in, 128,000 out | same |

The big one is [MAI-Base-2](/articles/mai-2), the 80B-active, 2.8T-total base model whose pre-training Microsoft wrote up in October: 50T tokens with Muon on 16k GB200s. The card's "MAI-Base-2" dependency, its "77 billion active, 3 billion embedded" and the data card's "MAI 80B" all describe that model. The card's own summary table disagrees with its body, though. It lists MAI Code 2 as "50B-100B (80B active)" and Flash as "5B-15B (12B active)", ranges that only make sense as active counts and contradict the 2.8T and 398B four paragraphs later. Flash's mid-training is "approximately 26.5T trillion tokens", which is a typo for something.

Post-training is where the coding comes from. From the cards, for reading the benchmarks later:

- **The RL ran in the product's harness.** "Reinforcement learning was run directly in the GitHub Copilot CLI and VS Code agent harnesses used in production." Hold on to that sentence for the next section.
- **Other labs' models wrote training data.** The data card names "GPT-5.6 Sol and GPT-6 Astra (OpenAI)" as generators of synthetic post-training data, alongside internal Microsoft models that generated, verified and graded tasks.
- **Copilot prompts seeded tasks.** "Conversation contexts (prompts and associated context only) from GitHub Copilot Free, Pro, and Pro+ users who have not opted out" were used to construct software-engineering tasks for synthetic data generation. The data card says production responses are not training targets, and that user interactions with the MAI model itself are not used.

Compared with [MAI-Code-1.1-Flash](/articles/windows-local-coding-models), which the card puts at 5B active, the jump is a new base, the 1M-token window (four times the old 256K, as the launch film says), and five reasoning efforts, `low` through `max`. Training ran from August to November 2026. The model card gives August 2026 as the pre-training data cut-off; the data card says pre-training datasets were "collected as late as March 2026".

## Four benchmarks, one harness

Here is the setup, from the card's section 3.1 and the announcement's footnotes. DeepSWE 1.1, Terminal-Bench 2.1 and SWE Atlas ran on MSBench, Microsoft's internal evaluation platform, "using the GitHub Copilot CLI (version 1.0.102) as the harness with subagents disabled". Every model ran at max reasoning effort. Each score is the mean single-attempt pass rate over three runs per task, and infrastructure errors count as failures. FrontierCode v1.1 scores and costs "are from Artificial Analysis".

What the four measure:

- **[DeepSWE 1.1](https://deepswe.datacurve.ai/)** (Datacurve): 113 original long-horizon tasks across five languages, graded by hidden tests.
- **Terminal-Bench 2.1**: 89 tasks in a sandboxed Linux terminal, each with its own verifier.
- **[SWE Atlas](https://arxiv.org/abs/2605.08366)** (Scale AI): 284 tasks from 18 maintained repositories, split into codebase Q&A (124), test writing (90) and refactoring (70), graded by programmatic checks plus rubrics.
- **FrontierCode 1.1** (Cognition, run by Artificial Analysis): agentic tasks in real repositories, graded on whether a maintainer would merge the change.

Microsoft's case for one harness is fair: "every model in a comparison was run in the same harness with the same settings, so pass rates reflect end-to-end task completion". If you use Copilot, Copilot CLI scores are the ones that describe your week. But it is not a neutral harness for these three models. MAI Code 2 was reinforced inside it, and nothing published says the other two were. A harness is a large part of an agent's score, and the one public comparison shows how large. [Vals.ai's Terminal-Bench 2.1 table](https://www.vals.ai/benchmarks/terminal-bench-2-1) runs every model in the Terminus 2 harness. It has Claude Opus 5.5 at 87.64%, at \$0.50 a task. Microsoft's run of the same model on the same benchmark in Copilot CLI: 78.7%, at \$1.842 a task. That is 8.9 points lower and 3.7 times the cost. Vals.ai's table states no effort setting, so some of the gap may be effort rather than harness. GPT-6 Luna is 73.03% on Vals.ai and 69.3% in Microsoft's run. Neither number is wrong. They answer different questions, and the launch numbers answer "how do these models do in our product's agent".

The official boards cannot settle it either way. DeepSWE's own leaderboard (mini-swe-agent, last updated 22 September) and the [Terminal-Bench 2.1 board](https://www.tbench.ai/) list none of the six models in Microsoft's two charts. Scale's SWE Atlas boards stop at older models. So for three of the four benchmarks the only scores for these models are Microsoft's.

## Rebuilding 98% and 96%

The chart data for MAI Code 2, as embedded on the model page:

| Benchmark | MAI Code 2 | GPT-6.1 Sol | Claude Opus 5.5 |
|---|---|---|---|
| DeepSWE 1.1 | 73.2% · \$0.618 | 74.6% · \$1.212 | 69.0% · \$10.717 |
| Terminal-Bench 2.1 | 84.6% · \$0.081 | 85.0% · \$0.265 | 78.7% · \$1.842 |
| SWE Atlas | 43.1% · \$0.228 | 47.4% · \$0.605 | 57.5% · \$4.234 |
| FrontierCode v1.1 | 52.0% · \$0.31 | 49.4% · \$0.96 | 56.0% · \$8.43 |
| **Mean** | **63.2% · \$0.309** | **64.1% · \$0.761** | **65.3% · \$6.306** |

Cost is US dollars per task, with MAI Code 2 at its promotional price. The means are plain unweighted averages of the four rows, and they reproduce: $(73.2 + 84.6 + 43.1 + 52.0)/4 = 63.225$, and the cost column gives \$0.3093 the same way, printed as \$0.309. Then the ratios, on the unrounded means:

$$
\frac{63.225}{64.1} = 98.6\%, \qquad \frac{63.225}{65.3} = 96.8\%, \qquad \frac{0.3093}{0.7605} = 40.7\%, \qquad \frac{0.3093}{6.3057} = 4.9\%
$$

Microsoft rounded both performance ratios down, to 98% and 96%, and printed the cost ratios as 40% and 5%. The headline is the data, stated conservatively. I found nothing cooked in the arithmetic.

What the average hides is more interesting than the average.

**MAI Code 2 beats GPT-6.1 Sol on one benchmark of four.** It is 0.4 points behind on Terminal-Bench 2.1 and 1.4 behind on DeepSWE 1.1, which on 89 and 113 tasks is a third of a task and about one and a half tasks. It is 4.3 points behind on SWE Atlas. It is 2.6 points ahead on FrontierCode, the one benchmark Microsoft did not run itself. "98% of Sol" means "tied with Sol on two, behind on one, ahead on one", which is a fair summary and a fair claim.

**Against Opus 5.5 the picture flips per benchmark.** MAI Code 2 is ahead on DeepSWE (4.2 points) and Terminal-Bench (5.9) and well behind on SWE Atlas (14.4) and FrontierCode (4.0). SWE Atlas is the benchmark most about reading a large codebase and writing tests and refactors a reviewer would accept, and it is where Opus is strongest in Microsoft's own run.

**Flash beats its big sibling on SWE Atlas**, 44.8% against 43.1%, in both the chart data and the card. A smaller model in the same family scoring higher on the codebase benchmark is not impossible over 284 rubric-graded tasks, but it is the kind of result a report would normally explain. This one doesn't.

## Cost per task is price times tokens

A cost per task is what a token costs times how many tokens the agent burns. Microsoft's pricing makes them easy to separate, because the MAI prices are an exact fraction of each rival's on every token type. From [GitHub's table](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing):

| Per 1M tokens | Input | Cached input | Output |
|---|---|---|---|
| MAI Code 2, promo to 17 May 2027 | \$0.50 | \$0.025 | \$2.50 |
| MAI Code 2, list from 17 May 2027 | \$1.00 | \$0.05 | \$5.00 |
| GPT-6.1 Sol (≤ 272K prompt) | \$2.00 | \$0.10 | \$10.00 |
| GPT-6.1 Terra (≤ 272K prompt) | \$1.00 | \$0.05 | \$5.00 |
| Claude Opus 5.5 | \$4.00 | \$0.20 | \$20.00 |
| MAI Code 2 Flash, promo | \$0.05 | \$0.005 | \$0.25 |
| MAI Code 2 Flash, list | \$0.10 | \$0.01 | \$0.50 |
| GPT-6 Luna (≤ 272K prompt) | \$0.10 | \$0.01 | \$0.50 |
| Claude Haiku 5.5 (≤ 100K prompt) | \$0.10 | \$0.01 | \$0.50 |

At the promo, every MAI Code 2 price is a quarter of GPT-6.1 Sol's and an eighth of Opus 5.5's. So if MAI Code 2 used the same tokens as Sol, its cost per task would be 25% of Sol's. It is 51% on DeepSWE ($0.618 / 1.212$), 31% on Terminal-Bench, 38% on SWE Atlas and 32% on FrontierCode. Divide by the 25% price ratio and MAI Code 2 spent 2.0x, 1.2x, 1.5x and 1.3x Sol's billed token volume on the same tasks. Against Opus, divide by 12.5% instead: MAI Code 2 spent between 0.29x and 0.46x of Opus's volume. Opus 5.5 at max effort in this harness is the most token-hungry of the three, and Sol the most frugal. (Cache writes, which GitHub bills for Sol and Opus and lists no price for on MAI, and the three tokenizers, make this a billed-volume ratio rather than a token count. So do the long-context tiers: Sol and Luna bill more above 272K-token prompts, and Haiku 5.5 bills five times as much above 100K, which matters for the Haiku ratio below. The direction holds either way.)

That split matters because one half of it expires. GitHub's pricing footnote is plain: "Starting May 17, 2027, pricing is \$1.00 per 1M input tokens, \$0.05 per 1M cached input tokens, and \$5.00 per 1M output tokens." The token volume stays. The price doubles. On DeepSWE, MAI Code 2 at list would cost \$1.236 a task against Sol's \$1.212, level. At list, MAI Code 2's mean cost per task is \$0.619: 81% of GPT-6.1 Sol's and 9.8% of Opus 5.5's. Its list price is exactly GPT-6.1 Terra's.

Flash is the same story with a sharper end. Its promo prices are half of GPT-6 Luna's and of Haiku 5.5's short-prompt tier. Microsoft's chart data:

| Benchmark | Code 2 Flash | GPT-6 Luna | Claude Haiku 5.5 |
|---|---|---|---|
| DeepSWE 1.1 | 59.9% · \$0.098 | 59.6% · \$0.159 | 46.0% · \$0.668 |
| Terminal-Bench 2.1 | 78.3% · \$0.023 | 69.3% · \$0.028 | 73.4% · \$0.067 |
| SWE Atlas | 44.8% · \$0.034 | 36.4% · \$0.051 | 42.1% · \$0.223 |
| **Mean** | **61.0% · \$0.052** | **55.1% · \$0.08** | **53.9% · \$0.319** |

The "65% and 20% of the cost" headline reproduces: $0.052/0.08 = 65\%$, and $0.052/0.319 = 16\%$, which Microsoft generously rounded up to 20% ("1/5" on the model page). On these three benchmarks Flash is better than both rivals, not merely "comparable": 61.0% against 55.1% and 53.9%. But Flash at half of Luna's price costs 65% of Luna per task, so it spends about 1.3x Luna's billed volume. When the promotion ends, Flash's prices become Luna's prices, token for token, and Flash costs 130% of what Luna costs per task.

Cost per task also charges a model only for the attempts it makes. What you pay to get a task done is cost per task divided by the pass rate, since the failures are billed too:

$$
\text{cost per resolved task} = \frac{\text{cost per task}}{\text{pass rate}}
$$

On that measure, at promo prices, MAI Code 2 averages \$0.52 per resolved task across the four benchmarks against \$1.29 for GPT-6.1 Sol and \$10.07 for Opus 5.5. At list, \$1.03. On DeepSWE alone at list, MAI Code 2 is \$1.69 per resolved task and Sol is \$1.63: the cheaper model is no longer cheaper on the longest tasks. Flash at list averages \$0.18 per resolved task against GPT-6 Luna's \$0.15, and costs more than Luna per resolved task on all three of its benchmarks, while still resolving more of them.

So the price-performance claim has a date on it. Until 17 May 2027, MAI Code 2 in Copilot is a large discount on the frontier and Flash is a discount on the small models. After it, Code 2 is a cheaper Sol by about a fifth on these tasks, and Flash is a slightly dearer Luna that passes more tasks. None of that is hidden. The footnote under each chart says the MAI cost "is shown at its 50% promotional price". It is just not the number in the headline.

## FrontierCode: the one number from outside

FrontierCode v1.1 is the only benchmark Microsoft did not run, and the only one I could check. [Artificial Analysis's FrontierCode 1.1 page](https://artificialanalysis.ai/evaluations/frontiercode) embeds its per-model records. Read on 20 November:

- **GPT-6.1 Sol (Max): 49.1%.** Microsoft's chart says 49.4%. Close enough to be a rerun of the same thing.
- **Claude Opus 5.5 (Max): 52.2%.** Microsoft's chart says 56.0%. AA's own summary line puts Opus 5.5 (Medium) at 57.1%. Neither of AA's public numbers is 56.0.
- **MAI Code 2: not listed.** No MAI model appears on that page, on AA's model leaderboard or on its coding-agent page, and `artificialanalysis.ai/models/mai-code-2` is a 404.

The Opus mismatch does not flatter MAI. With AA's Max figure in place of 56.0, Opus's mean falls to 64.35%, and MAI Code 2 becomes 98.2% of Opus rather than 96.8%. My guess is a different snapshot or effort setting, but the card doesn't say, and Microsoft's 52.0% for its own model cannot be found at the source it cites. AA may have run it privately ahead of launch. That is plausible and unverifiable.

Two more things about the comparison set. AA marks GPT-6.1 Sol as deprecated: GPT-6.2 Sol shipped the same day as MAI Code 2, at the same \$2/\$10 in Copilot. A benchmark run finished before launch can't include a model released at launch, so this is timing, not selection. And the Flash comparison uses three benchmarks, all Microsoft-run. FrontierCode, the external one, is dropped for Flash. AA has GPT-6 Luna (Max) at 41.9% and Haiku 5.5 (Max) at 41.8% on it, so there was a reference to compare against.

DeepSWE 1.1 at 60.2% against 73.2%. Flash at 27.4% against 59.9%. SWE Atlas at 80.9% and 65.2% against 43.1% and 44.8%: almost double, which suggests a different subset or a different grading threshold rather than a different harness. The card also reports Terminal-Bench 4, in its loss-of-control section, with no harness stated: 26.3% for MAI Code 2 and 2.5% for Flash. AA's [Terminal-Bench 4.0](https://www.tbench.ai/news/terminal-bench-4-0) records, in AA's own harness, have GPT-6.1 Sol (Max) at 56.1%, Opus 5.5 (Max) at 59.6%, Haiku 5.5 (Max) at 32.8% and GPT-6 Luna (Max) at 12.6%. Harnesses differ, so this is a direction rather than a gap, but the direction is clear: on the hardest terminal benchmark in circulation, MAI Code 2 sits below Haiku 5.5. That is consistent with Microsoft's own scoping, which is the most honest line in the launch: the models are "explicitly not yet tuned for harder problems, like fundamental science research and very long-horizon agentic work". The headline average was built from benchmarks where that limitation doesn't bite.

Most of the card's 22 pages are safety and frontier risk, and a few findings belong next to a coding model you might let run commands:

- Microsoft rates both models **High** for CBRN and for offensive cyberoperations, "in line with other similar models (e.g., GPT-5.6 Sol and GPT-5.6 Luna)", and deploys them behind a two-tier classifier: a fast bio/cyber detector, then "a specially trained safety reasoner" that blocks responses above its policy line.
- Its red team assessed both models as "similar in alignment to GPT-5.6 Sol but less aligned than GPT-6", observing "repeated instances of the model circumventing safeguards, misleading supervisors, interfering with human oversight". The card's limitations list adds that in long sessions the models "can repeat tool calls, under-use the existing code base, drift from instructions or stop before fully verifying their work".
- In a simulated social network with a covert brief to swing a referendum, MAI Code 2 with safeguards declined all four arms under the standard prompt, and ran the campaign in three of four once the request was framed as a game. Both Flash checkpoints ran it in every arm, eight of eight.

For agentic coding the card's advice is the usual one, and it applies with some force here: run the agent in a sandbox, with least privilege, and review what it merges.

## Where you can use it, and what is open

- **GitHub Copilot**, from 17 November. Per the [changelog](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot/), MAI Code 2 is on Copilot Pro, Pro+, Max, Business and Enterprise; Flash is on every plan from Free and Student up. Both are in the model picker in VS Code, Visual Studio, the Copilot CLI, the cloud agent, the Copilot app, github.com, mobile, JetBrains, Xcode and Eclipse, billed per token under usage-based billing. Business and Enterprise admins control them through the model policy, and new models are on by default.
- **Microsoft Foundry**: Flash only, in limited-access preview, through the OpenAI-compatible Responses API (the card's section 2.4). No Foundry price is published.
- **Everywhere else**: "Soon, we'll be releasing them on OpenRouter, Vercel, Hermes, OpenCode, and Kilo." No date.
- **Open**: nothing. "Model weights are not distributed", says the card. The licence is "various product and service terms where the model is deployed". Microsoft's Custom Models programme will fine-tune Flash for customers; the model page quotes Woven by Toyota on a MISRA-fix fine-tune and AT&T on a 5G-analysis one.

MAI Code 2 at list lands at GPT-6.1 Terra's price, and Flash at list at Luna's and Haiku's. Microsoft chose to compare against the models one tier up (Sol, Opus) for Code 2 and the same tier for Flash. If Terra's coding numbers in the same harness were close to Code 2's, the "frontier price-performance" framing would get harder after May. That comparison isn't in the launch.

## What I'd do with it

If you are in Copilot already, try MAI Code 2 for the work Microsoft says it is for: multi-file changes, debugging, tests. At \$0.50/\$2.50 it is cheap, and in Microsoft's own harness it is within a task or two of GPT-6.1 Sol on two of four benchmarks. Flash is a good default for triage and small edits; it scored higher than GPT-6 Luna and Haiku 5.5 on all three of its benchmarks, though only by 0.3 points over Luna on DeepSWE.

I would not plan a budget on those prices. The cost advantage is half price and half token volume, and the price half ends on 17 May 2027, at which point Code 2 is about a fifth cheaper than Sol per task and Flash costs more than Luna. I would not read "frontier" into it either: SWE Atlas favours Opus by 14 points, Terminal-Bench 4 puts MAI Code 2 below Haiku 5.5, and Microsoft itself says long-horizon work is out of scope. And I'd wait for a number nobody at Microsoft produced. The one outside benchmark in the launch can't be found at its source for MAI, and doesn't match its source for Opus. When Artificial Analysis, Vals.ai or the DeepSWE board runs these models in a harness they weren't trained in, the claim gets interesting. Until then it is a well-arithmetised claim about Microsoft's agent on Microsoft's platform, which is a narrower thing than the post says.
